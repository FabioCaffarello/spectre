# Security Policy

## Reporting a vulnerability

If you discover a security issue in Spectre, please report it
privately. Do not open a public issue.

- **Email:** fabio.caffarello@gmail.com
- **Subject:** start with `[security]`

Please include:

- A description of the issue
- Steps to reproduce
- The version or commit affected
- Your assessment of impact

## Response timeline

- **Acknowledgement:** within 48 hours of receipt
- **Initial assessment:** within 7 days
- **Resolution target:** depends on severity; we aim for 90 days from
  initial report to public disclosure for confirmed issues

## Supported versions

Spectre is currently in alpha. Only the `main` branch is supported.
Once we reach `v1.0`, this policy will be updated to specify supported
release lines.

## Coordinated disclosure

We follow standard coordinated disclosure practice. We will work with
reporters to agree on a disclosure timeline. Credit will be given in
release notes unless the reporter requests otherwise.
